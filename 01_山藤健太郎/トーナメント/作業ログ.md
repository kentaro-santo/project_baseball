## 5. スクリプト設計（generate_schedule.py）

### キャンバス設定
```python
fig, ax = plt.subplots(figsize=(15, 13))
ax.set_xlim(0, 15)
ax.set_ylim(0, 14)
```

### レイアウト構造
```
y=14 ─ タイトル（中国五大学学生競技大会　硬式野球の部）
y=13 ─ 日程（令和8年度 8月8日〜9日）
y=12 ─ 開催場所（広島大学野球場）
y=11 ─ 《本戦》ラベル / 《三位決定戦》ラベル
y=6〜11 ─ 左：本戦ブラケット ／ 右：三位決定戦ブラケット
y=5.6 ─ 破線区切り
y=5.3〜2 ─ 試合スケジュール表（6行）
y=1.7 ─ ※注記1（表彰式）
y=1.3 ─ ※注記2（補助内容）
```

### 表のカラム構成
```
日程 | 時間 | 試合 | 対　戦 | 補　助
```

### 主要パラメータ
```python
ROW_H   = 0.50   # 行の高さ
TABLE_Y = 5.30   # 表の開始Y座標（破線より下）
HDR_H   = 0.45   # ヘッダー高さ
TBL_W   = 14.6   # 表の横幅
```

## 9. 注意事項・ハマりポイント

| 問題 | 対処法 |
|------|--------|
| 日本語フォントが文字化け | `plt.rcParams['font.family']` に Yu Gothic / Meiryo を指定 |
| 「広島」の文字が化ける（U+5CF3） | Pythonで `txt.replace('\u5e83\u5cf3', '\u5e83\u5cf6')` で修正 |
| PowerShellで `&&` エラー | コマンドを1行ずつ分けて実行 |
| テキストが表の行と重なる | `TABLE_Y` と `ylim` を調整してスペースを確保 |
| ブラケットの線が途切れる | `hline` の終端X座標を縦線の位置まで延長する |
