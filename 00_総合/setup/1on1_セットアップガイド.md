# 1on1 野球記録アプリ セットアップガイド

## 📋 概要
このアプリは、野球の1対1練習（投手 vs 打者）の記録と分析ができるツールです。
- **記録モード**: 投球コース、球速、判定などをリアルタイムで記録
- **分析モード**: 過去のデータを使って投手・打者の成績を可視化

---

## 🔧 準備（初回のみ）

### 1. Pythonのインストール確認
パソコンにPythonがインストールされているか確認してください。

**確認方法:**
1. スタートメニューで「PowerShell」または「コマンドプロンプト」を開く
2. 以下を入力して Enter を押す
```
python --version
```
3. バージョン情報が表示されたら OK（例: `Python 3.11.9`）

> ⚠️ 「'python' は認識されません」と出た場合は、[Python公式サイト](https://www.python.org/)からインストールしてください

---

### 2. 必要なパッケージをインストール

アプリに必要なツール（パッケージ）をインストールします。

**手順:**
1. PowerShell または コマンドプロンプトを開く
2. 以下のコマンドを貼り付けて Enter を押す

```powershell
python -m pip install streamlit pandas matplotlib plotly streamlit-drawable-canvas
```

3. 完了メッセージが表示されるまで待つ（1〜5分程度）

> 💡 Tip: 一度インストールすれば、次回以降は実行するだけで OK

## 🎯 アプリの使い方

### 📝 記録モード

1. **サイドバーで選手を登録**
   - 「メンバー管理 (追加・削除)」を展開
   - 投手・打者を登録

2. **対戦設定**
   - 投手・打者を選択
   - ボール・ストライク数を確認

3. **投球を記録**
   - ① **球種**: ストレート、スライダーなどを選択
   - ② **球速**: キーパッドで入力（例: 145）
   - ③ **コース**: キャンバスをクリックして投球位置を記録
   - ④ **判定**: 見逃し、空振り、ファウル、インプレーを選択
   - **🔥 保存**: ボタンをクリック

4. **修正・削除**
   - 履歴から修正対象を選択 → 「修正」または「削除」

### 📈 分析モード

1. **フィルター設定** (サイドバー)
   - 期間、投手、打者、球種を絞り込み

2. **投手分析**
   - 投球チャートで投球位置を可視化
   - ストライク率や初球ストライク率を確認

3. **打者分析**
   - 打球チャートで打球位置を確認
   - コース別スイング率や打率を確認

## 🐛 トラブルシューティング

### Q. 「'python' は認識されません」と出る
**A.** Pythonがインストールされていない、または PATH が設定されていません
- [Python公式サイト](https://www.python.org/)から Python 3.10 以上をインストール
- インストール時に「Add Python to PATH」にチェックを入れる

### Q. 「ModuleNotFoundError」と出る
**A.** パッケージがインストールされていません
- 以下を実行してください:
```powershell
python -m pip install streamlit pandas matplotlib plotly streamlit-drawable-canvas
```

### Q. ブラウザが起動しない
**A.** 手動でブラウザを開いてください
- アドレスバーに `http://localhost:8501` を入力

### Q. 「Address already in use」と出る
**A.** ポート8501が他のアプリで使用されています
- PowerShell を再起動してから再実行
- **または** 以下で別のポートで起動:
```powershell
python -m streamlit run "C:\Users\スコアボード\OneDrive - Hiroshima University\h0riy\baseball\1on1.py" --server.port 8502
```
