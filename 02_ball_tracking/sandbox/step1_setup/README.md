# ステップ1: AIを動かすための準備（環境構築）

プログラミングが初めてでも大丈夫です！まずは、AIを動かすための「作業机」を準備しましょう。
今回は「Google Colab（グーグル・コラボ）」という、Googleが無料で提供している強力なパソコンをインターネット越しに使います。

## やること
1. Googleアカウントにログインした状態で [Google Colab](https://colab.research.google.com/) にアクセスし、「ノートブックを新規作成」をクリックします。
2. 上部メニューの **「ランタイム」** ＞ **「ランタイムのタイプを変更」** を選びます。
3. 「ハードウェア アクセラレータ」を **「T4 GPU」** 等に変更して「保存」を押します（これでAIの計算が劇的に速くなります！）。
4. 画面に出てくる「コードセル（文字を入力できる枠）」に、以下のコードをコピーして貼り付けます。
5. 枠の左側にある **再生ボタン（▶︎）** を押して実行します。

## 実行するコード

Colabでは、先頭に `!` をつけると、Colabのパソコン自体にソフトをインストールする命令になります。

```python
# 1. まずは「YOLOv8」という最新の画像認識AIをインストールします
!pip install ultralytics

# 2. ここから下はPythonのコードです。GPUが正しく設定されたか確認します
import torch
from ultralytics import YOLO

print("--- 実行環境の確認 ---")
if torch.cuda.is_available():
    print("大成功！GPU（強力な計算機）が使える状態です！")
    print("使っているGPUの名前:", torch.cuda.get_device_name(0))
else:
    print("注意: GPUが使えません。上の手順に戻ってランタイムの設定を確認してください。")

# 3. YOLOの標準的なAIモデルをダウンロードします
model = YOLO('yolov8n.pt')
print("YOLOv8の準備が完了しました！次に進みましょう。")
```

文字がいっぱい出てきますが、最後に「YOLOv8の準備が完了しました！」と表示されれば成功です！
